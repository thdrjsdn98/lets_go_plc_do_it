01. 자기유지회로 기본

1. 자기유지회로란?

기동버튼(I0.0)을 눌렀다 떼면 보통 출력은 바로 꺼진다. 버튼을 떼도 스스로 통전 상태를 유지하도록 만든 것이 자기유지회로다. 기동버튼과 병렬로, 출력 코일 자신의 A접점(Q0.0)을 추가하면 된다.

2. 래더 예제

기동(I0.0) 또는 자기유지접점(Q0.0)이 통전되고, 정지(I0.1)가 눌리지 않은 상태에서 출력 코일 Q0.0이 ON

3. 동작 순서

① I0.0(기동)을 누르면 Q0.0 ON → ② 손을 떼도 Q0.0의 A접점(자기유지접점)이 통전 중이므로 유지 → ③ I0.1(정지, B접점)을 누르면 경로가 끊어져 Q0.0 OFF.

4. 자기유지회로가 필요한 이유

만약 자기유지 없이 버튼을 누르는 동안에만 모터를 돌리려 한다면, 작업자가 계속 버튼을 누르고 있어야 하므로 비현실적이다. 자기유지회로는 '한 번 누르면 계속 동작, 다시 누르면(정지버튼) 멈춤'이라는 실무에서 가장 흔한 요구사항을 구현하는 기본 패턴이다.

5. SET/RESET으로 구현하는 대안

같은 동작을 SET(S)/RESET(R) 코일로도 구현할 수 있다. 기동버튼 조건에서 Q0.0을 SET, 정지버튼 조건에서 Q0.0을 RESET하면 접점 자기유지 없이도 동일한 효과를 낸다. 두 방식 모두 실무에서 널리 쓰이며, 회사·팀의 코딩 컨벤션에 따라 선택하면 된다.

🔰 문버팀쇠를 떠올리면

자기유지회로는 문이 저절로 닫히지 않도록 문 밑에 버팀쇠를 괴어두는 것과 같다. 기동버튼(손)을 떼도 자기 자신의 접점(버팀쇠)이 회로를 계속 열어둔 상태로 유지시켜 주는 것이 핵심 원리다.
✏️ 단원 확인문제 (4문제)
점수: 0 / 100점 (정답 0 / 4문제)

Q1. 자기유지회로에서 병렬로 추가하는, 출력 자신의 접점을 무엇이라 하는가? (한글) (단답형)

💡 해설: 출력 코일 자신의 A접점을 기동버튼과 병렬로 넣어 스스로 회로를 유지시키는 것을 자기유지접점이라 합니다.

Q2. 자기유지회로에서 정지버튼에 주로 사용하는 접점 종류는?

💡 해설: 정지버튼은 눌렸을 때 회로를 끊어야 하므로 일반적으로 B접점(NC)을 사용합니다.

Q3. 자기유지회로가 필요한 이유로 가장 적절한 것은?

💡 해설: 자기유지회로가 없다면 버튼을 계속 누르고 있어야 하므로 실무에서는 비현실적입니다.

Q4. 자기유지회로와 동일한 동작을 SET/RESET 코일로 구현하려면?

💡 해설: 기동버튼 조건에서 출력을 SET하고 정지버튼 조건에서 RESET하면 자기유지와 동일한 효과를 낼 수 있습니다.

02. 자기유지회로 응용 - 다중 정지버튼

1. 여러 위치에 정지버튼 설치하기

현장에서는 안전을 위해 여러 지점에 정지버튼을 설치하는 경우가 많다. 이때 정지버튼들은 모두 직렬로 연결하여, 어느 하나라도 눌리면 즉시 회로가 끊어지도록 구성한다.

2. 반대로 기동버튼은?

여러 위치에서 기동시킬 수 있게 하려면 기동버튼들을 서로 병렬로 연결하여, 그 중 하나만 눌러도 기동되도록 구성한다.

3. 정지 우선의 원칙

안전 설계에서는 '정지 우선(Stop-priority)' 원칙을 지키는 것이 중요하다. 즉, 기동과 정지 신호가 동시에 들어와도 항상 정지가 이기도록 회로를 구성해야 하며, 이는 정지버튼(B접점)을 항상 기동버튼보다 논리적으로 뒤(코일 쪽에 더 가깝게)에 직렬로 배치함으로써 자연스럽게 만족된다.

4. 비상정지와 일반 정지의 구분

일반 정지버튼과 별개로 비상정지(E-STOP)가 있는 설비라면, 비상정지는 모든 정지버튼보다도 상위(가장 코일에 가까운 곳)에 별도로 직렬 연결해, 어떤 상황에서도 최우선으로 작동하도록 구성해야 한다.

🔰 비상구가 여러 개인 것과 같다

정지버튼을 여러 개 두는 것은 큰 건물에 비상구를 여러 곳에 만들어두는 것과 비슷하다. 어느 비상구(정지버튼)로 나가도 안전해야 하듯, 여러 정지버튼 중 어느 것을 눌러도 모터가 확실히 멈춰야 하므로 정지버튼들은 서로 직렬로 연결한다.
✏️ 단원 확인문제 (4문제)
점수: 0 / 100점 (정답 0 / 4문제)

Q1. 여러 위치의 정지버튼을 배선할 때 일반적인 연결 방식은?

💡 해설: 정지버튼을 여러 개 직렬로 연결하면 어느 하나만 눌려도 회로가 차단됩니다.

Q2. 정지버튼을 여러 개 직렬 연결하는 이유는?

💡 해설: 직렬 연결은 어느 하나의 접점만 끊어져도 전체 회로가 차단되는 특성을 이용한 것입니다.

Q3. 기동과 정지 신호가 동시에 들어와도 항상 정지가 우선하도록 하는 안전 설계 원칙은?

💡 해설: 안전 설계에서는 기동과 정지가 동시에 들어와도 항상 정지가 이기도록 하는 정지 우선 원칙을 지켜야 합니다.

Q4. 비상정지(E-STOP)는 일반 정지버튼과 비교해 회로상 어디에 배치해야 하는가?

💡 해설: 비상정지는 어떤 상황에서도 최우선으로 작동해야 하므로 다른 정지버튼보다도 상위에 배치합니다.

03. 인터록(Interlock) 회로

1. 인터록이란?

모터의 정회전(Q0.0)과 역회전(Q0.1)처럼 절대 동시에 켜지면 안 되는 두 출력이 있을 때, 서로 상대방 코일의 B접점을 자기 회로에 직렬로 넣어 동시 투입을 막는 방법이다.

2. 안전상 유의사항

래더 안에서의 전기적 인터록만 믿지 말고, 실제 현장에서는 정역회전 전자접촉기(MC) 사이에 기계적 인터록도 함께 적용하는 것이 일반적인 안전 설계 원칙이다.

3. 왜 두 가지 인터록이 모두 필요한가

전기적 인터록(래더 로직)만 있으면, 만약 접촉기 자체의 고장(융착 등)으로 실제 접점이 붙어버린 경우에는 PLC가 이를 알 수 없어 두 방향이 동시에 통전될 위험이 있다. 기계적 인터록은 이런 하드웨어적 고장 상황에서도 물리적으로 동시 투입을 막아주는 최후의 안전장치 역할을 한다.

4. 인터록의 다른 활용 예

정역회전 모터 외에도, 2개의 펌프 중 하나만 가동되어야 하는 경우, 출입문 두 개가 동시에 열리면 안 되는 경우 등 '동시에 둘 다 작동하면 안 되는' 모든 상황에 인터록 개념을 응용할 수 있다.

🔰 동시에 열 수 없는 두 문

인터록은 정역회전처럼 절대 동시에 켜지면 안 되는 두 출력이 있을 때, 한쪽이 켜져 있으면 다른 쪽이 절대 켜지지 않도록 막아주는 안전장치다. 한쪽 문이 열려 있으면 반대쪽 문은 절대 열리지 않게 잠가두는 것과 같은 개념이다.
✏️ 단원 확인문제 (4문제)
점수: 0 / 100점 (정답 0 / 4문제)

Q1. 정회전(Q0.0)과 역회전(Q0.1)이 동시에 켜지는 것을 막기 위해 각 코일 앞에 넣는 것은?

💡 해설: 서로 상대방 출력의 B접점을 직렬로 넣으면 한쪽이 켜져 있는 동안 다른 쪽 경로가 끊어집니다.

Q2. 인터록과 함께 현장에서 추가로 적용하는 물리적 안전장치는?

💡 해설: 전기적 인터록뿐 아니라 기계적 인터록도 함께 적용하는 것이 안전 설계의 일반적인 원칙입니다.

Q3. 전기적 인터록만으로는 대응할 수 없는 상황은?

💡 해설: 접촉기가 물리적으로 고장나 붙어버리면 PLC 로직만으로는 감지·차단이 불가능해 기계적 인터록이 필요합니다.

Q4. 인터록 개념을 응용할 수 있는 상황으로 가장 적절한 것은?

💡 해설: 인터록은 정역회전뿐 아니라 동시 작동이 금지되는 모든 상황(펌프, 출입문 등)에 응용할 수 있습니다.

04. 우선순위 회로 (선입력/후입력 우선)

1. 선입력우선회로

두 버튼 중 먼저 눌린 것만 유효하게 만드는 회로다. 각 출력 코일 앞에 상대방 출력의 B접점을 넣어, 이미 한쪽이 켜져 있으면 나중에 눌린 버튼이 무시되도록 구성한다.

2. 후입력우선회로

반대로 나중에 눌린 버튼이 이전 상태를 덮어쓰도록 만드는 회로로, 상대방 출력을 강제로 RESET 시키는 로직을 추가해 구현한다.

3. 실무에서의 활용 예

여러 작업자가 각자의 스테이션에서 동시에 신호를 보낼 수 있는 설비에서, 먼저 요청한 작업을 끝까지 처리하고 싶다면 선입력우선을, 가장 최근 요청이 항상 우선되어야 하는 상황(예: 비상 알림 갱신)이라면 후입력우선을 선택한다.

4. 인터록과의 관계

선입력우선회로는 사실상 인터록에 '먼저 켜진 쪽이 이긴다'는 규칙을 추가한 형태로 볼 수 있다. 인터록의 기본 구조(상대방 B접점 직렬)를 이해하고 있으면 우선순위 회로도 자연스럽게 이해할 수 있다.

🔰 먼저 누른 사람이 이기는 게임

선입력 우선 회로는 여러 버튼 중 '가장 먼저' 눌린 신호만 유효하게 인정하는 선착순 버튼과 같다. 반대로 후입력 우선은 나중에 누른 신호가 이전 신호를 덮어쓰는 방식으로, 설비의 안전 요구사항에 따라 어떤 방식이 필요한지 결정해야 한다.
✏️ 단원 확인문제 (4문제)
점수: 0 / 100점 (정답 0 / 4문제)

Q1. 두 버튼 중 먼저 눌린 것만 유효하게 만드는 회로를 무엇이라 하는가?

💡 해설: 선입력우선회로는 먼저 눌린 신호만 유효하게 만드는 회로입니다.

Q2. 후입력우선회로는 어떤 특징을 갖는가?

💡 해설: 후입력우선회로는 나중에 들어온 신호가 이전 상태를 덮어쓰도록 설계됩니다.

Q3. 가장 최근 요청이 항상 우선되어야 하는 상황(예: 비상 알림 갱신)에 적합한 회로는?

💡 해설: 가장 최근 신호가 우선되어야 한다면 후입력우선회로가 적합합니다.

Q4. 선입력우선회로는 어떤 회로의 구조를 기반으로 확장한 것으로 볼 수 있는가?

💡 해설: 선입력우선회로는 인터록의 기본 구조(상대방 B접점 직렬)에 '먼저 켜진 쪽이 이긴다'는 규칙을 더한 형태로 볼 수 있습니다.

05. 지연 기동·지연 정지 회로

1. 지연 기동 (TON 활용)

버튼을 누른 뒤 일정 시간이 지나야 실제로 기동되게 하고 싶을 때 TON(On-Delay) 타이머를 사용한다.

2. 지연 정지 (TOF 활용)

모터가 꺼진 후에도 환기팬을 일정 시간 더 돌리고 싶은 경우처럼, 신호가 꺼진 뒤에도 일정 시간 출력을 유지하고 싶을 때는 TOF(Off-Delay) 타이머를 사용한다.

3. 지연 기동의 실무 활용 예

대형 모터는 기동 순간 큰 돌입전류가 흐르기 때문에, 여러 대의 모터를 동시에 기동하지 않고 TON으로 몇 초씩 간격을 두고 순서대로 기동시키면 전체 설비의 전기적 부담을 줄일 수 있다.

4. 지연 정지의 실무 활용 예

집진기(먼지를 빨아들이는 팬)는 본 설비가 멈춘 후에도 남은 먼지를 마저 빨아들이도록 일정 시간 더 동작해야 하는 경우가 많다. 이때 TOF를 이용해 본 설비 정지 신호가 꺼진 뒤에도 집진기가 몇 초~몇 분 더 동작하도록 구성한다.

🔰 예열 시간을 기다리는 것

지연 기동은 버튼을 누른 즉시가 아니라 일정 시간(예열 시간처럼) 기다렸다가 켜지는 것이고, 지연 정지는 버튼을 눌러도 바로 꺼지지 않고 잠시 후에(냉각 팬처럼) 꺼지는 것이다. 히터나 모터 보호를 위해 이런 지연 동작이 자주 필요하다.
✏️ 단원 확인문제 (4문제)
점수: 0 / 100점 (정답 0 / 4문제)

Q1. 모터가 꺼진 후에도 환기팬을 일정 시간 더 돌리고 싶을 때 적합한 타이머는?

💡 해설: TOF(Off-Delay)는 입력이 꺼진 뒤에도 설정 시간만큼 출력을 유지시키는 데 적합합니다.

Q2. 버튼을 누른 뒤 일정 시간이 지나야 실제로 기동되게 하고 싶을 때 적합한 타이머는?

💡 해설: TON(On-Delay)은 입력이 켜진 뒤 설정 시간이 지나야 출력이 켜지도록 하는 데 적합합니다.

Q3. 여러 대의 대형 모터를 순서대로 지연 기동시키는 주된 이유는?

💡 해설: 대형 모터를 동시에 기동하면 돌입전류가 겹쳐 전기적 부담이 커지므로, 순서대로 지연 기동시켜 부담을 분산합니다.

Q4. 집진기가 본 설비 정지 후에도 한동안 더 동작해야 하는 경우 적합한 타이머는?

💡 해설: 본 설비가 꺼진 뒤에도 일정 시간 더 동작해야 하는 경우이므로 TOF(Off-Delay)가 적합합니다.

06. 비상정지(E-STOP) 회로

1. B접점을 쓰는 이유 (Fail-safe)

비상정지(E-STOP) 스위치는 일반적으로 B접점(NC)으로 설계한다. 이렇게 하면 배선이 단선되거나 커넥터가 빠지는 고장이 나도 회로가 자동으로 정지 상태가 되어(Fail-safe) 더 안전하다.

2. 리셋(복귀) 절차

비상정지가 작동된 뒤에는 원인을 해결하고 수동으로 리셋(복귀) 조작을 해야만 다시 정상 운전으로 돌아갈 수 있도록 설계하는 것이 일반적이다(자동 복귀는 안전상 지양).

3. 비상정지 버튼의 물리적 특징

비상정지 버튼은 대부분 누르면 잠기고(래치), 돌리거나 당겨야 풀리는 구조로 만들어져 있다. 이는 눌린 상태가 실수로 저절로 풀리지 않도록 하기 위한 물리적 안전장치다.

4. 안전 등급이 필요한 경우

단순 B접점 하나로는 충분하지 않은 고위험 설비라면, 이중화된 접점과 안전 릴레이(Safety Relay) 또는 F-CPU를 활용해 하나의 접점이 고장 나도 안전이 유지되도록 설계해야 한다.

🔰 무조건 최우선으로 이기는 규칙

비상정지 버튼은 다른 어떤 조건보다도 최우선으로 모든 것을 멈춰야 하는 만능 브레이크와 같다. 그래서 다른 모든 회로 경로보다 앞단에, B접점으로 직렬 연결해 어떤 상황에서도 확실히 전원을 차단하도록 설계한다.
✏️ 단원 확인문제 (4문제)
점수: 0 / 100점 (정답 0 / 4문제)

Q1. 비상정지(E-STOP) 스위치가 일반적으로 B접점(NC)으로 설계되는 이유는?

💡 해설: B접점으로 설계하면 단선 등의 고장이 발생해도 안전한 방향(정지)으로 동작합니다(Fail-safe).

Q2. 비상정지가 작동된 후 다시 정상 운전으로 복귀하려면 일반적으로 필요한 조작은?

💡 해설: 안전상 비상정지 이후에는 수동으로 리셋(복귀) 조작을 해야 정상 운전으로 돌아가도록 설계하는 것이 일반적입니다.

Q3. 비상정지 버튼이 눌린 뒤 저절로 풀리지 않도록 만드는 물리적 구조는?

💡 해설: 비상정지 버튼은 실수로 풀리지 않도록 누르면 잠기고 돌리거나 당겨야 풀리는 구조로 설계됩니다.

Q4. 고위험 설비에서 접점 하나의 고장에도 안전을 유지하려면 무엇을 활용해야 하는가?

💡 해설: 고위험 설비는 이중화된 접점과 안전 릴레이 또는 F-CPU를 활용해 단일 고장에도 안전을 유지하도록 설계해야 합니다.

07. 실습 - 모터 정역회전 제어 종합

1. 입출력 정의

정회전버튼(I0.0), 역회전버튼(I0.1), 정지버튼(I0.2, B접점), 정회전출력(Q0.0), 역회전출력(Q0.1)로 구성한다.

2. 로직 결합

각 회전 방향마다 자기유지(자신의 A접점 병렬)와 인터록(상대방 출력의 B접점 직렬)을 함께 적용하고, 정지버튼(I0.2)은 양쪽 회로 모두에 직렬로 연결해 어느 방향이든 즉시 정지되게 한다.

3. 방향 전환시 지연시간 추가하기

모터가 회전하는 도중 바로 반대 방향으로 전환하면 큰 전기적·기계적 충격이 발생할 수 있다. 실무에서는 정지 후 일정 시간(TON) 지연을 두어, 모터가 완전히 멈춘 뒤에야 반대 방향 기동이 가능하도록 로직을 보강하는 경우가 많다.

4. 확장 아이디어 - 과부하 보호 연동

모터 과부하 계전기(EOCR 등)의 신호를 입력 접점으로 받아, 인터록 로직에 추가로 직렬 연결하면 과부하 발생시 자동으로 모든 회전 방향을 차단하는 안전한 설계로 확장할 수 있다.

🔰 지금까지 배운 걸 조립하는 시간

정역회전 제어는 자기유지 + 인터록 + 정지회로를 모두 합친 종합 실습이다. 새 개념이 나오는 게 아니라, 앞 단원에서 배운 부품들을 레고처럼 조립하는 과정이므로 막히면 앞 단원을 하나씩 다시 떠올리며 맞춰보면 된다.
✏️ 단원 확인문제 (4문제)
점수: 0 / 100점 (정답 0 / 4문제)

Q1. 정역회전 모터 제어에서 자기유지와 인터록을 함께 쓰는 이유는?

💡 해설: 자기유지로 버튼을 떼도 출력이 유지되게 하고, 인터록으로 정역회전이 동시에 켜지지 않도록 함께 적용합니다.

Q2. 정지버튼(I0.2)은 정회전/역회전 두 코일 회로 각각에 대해 어떻게 연결하는가?

💡 해설: 정지버튼은 정회전, 역회전 두 회로 모두에 직렬로 연결해 어느 방향이든 즉시 정지시킬 수 있게 합니다.

Q3. 모터의 회전 방향을 바로 반대로 전환할 때 발생할 수 있는 문제는?

💡 해설: 회전 중 바로 반대 방향으로 전환하면 전기적·기계적으로 큰 충격이 발생할 수 있어 지연시간을 두는 것이 안전합니다.

Q4. 모터 과부하 계전기 신호를 인터록 로직에 연동하면 얻는 효과는?

💡 해설: 과부하 계전기 신호를 인터록에 추가하면 과부하 상황에서 자동으로 모든 방향의 기동을 차단하는 안전한 설계가 됩니다.

08. 자동/수동 전환회로

1. 자동/수동 전환의 필요성

설비 점검이나 초기 세팅시에는 PLC 로직 대신 사람이 직접 버튼으로 제어하고 싶은 경우가 있다. 이를 위해 자동/수동 셀렉터 스위치를 두고 모드에 따라 제어 경로를 분리한다.

2. 인터록 적용

셀렉터 스위치의 상태는 입력접점(예: I0.5)으로 읽어들이며, 자동 모드일 때는 수동 조작 버튼의 영향을 차단하고, 수동 모드일 때는 PLC 자동 로직의 출력을 차단하도록 서로 인터록을 건다.

3. 실무 설계 패턴

실제 로직은 보통 '(자동모드 AND 자동로직출력) OR (수동모드 AND 수동버튼)' 형태의 구조로 짜여진다. 이렇게 하면 최종 출력 코일 하나에 자동/수동 두 경로가 안전하게 합쳐진다.

4. 수동 모드에서도 안전장치는 살아있어야 한다

수동 모드로 전환했다고 해서 비상정지나 인터록 같은 안전 로직까지 무시되어서는 안 된다. 안전 관련 조건은 자동/수동 모드와 무관하게 항상 최우선으로 적용되도록 설계하는 것이 원칙이다.

🔰 리모컨과 수동 스위치를 같이 쓰는 선풍기

자동/수동 전환회로는 리모컨(자동 로직)과 본체의 수동 버튼을 모두 갖춘 선풍기와 비슷하다. 선택 스위치로 지금 어느 쪽 신호를 받을지 미리 정해두고, 그 상태에 따라 자동 로직 또는 수동 버튼 신호만 실제 출력으로 연결되도록 구성하는 것이 핵심이다.
✏️ 단원 확인문제 (4문제)
점수: 0 / 100점 (정답 0 / 4문제)

Q1. 자동/수동 전환 스위치가 자동 위치에 있을 때 일반적으로 비활성화되는 것은?

💡 해설: 자동 모드에서는 수동 조작 버튼이 출력에 영향을 주지 않도록 차단하는 것이 일반적입니다.

Q2. 자동/수동 전환에서 셀렉터스위치의 상태를 읽어들이는 대표적 방식은?

💡 해설: 셀렉터스위치의 상태는 일반적인 입력접점(%I)을 통해 PLC가 읽어들입니다.

Q3. 자동/수동 전환 로직의 일반적인 구조로 옳은 것은?

💡 해설: 자동/수동 두 경로를 각각 AND로 묶고 이를 OR로 합치는 구조가 일반적인 설계 패턴입니다.

Q4. 수동 모드로 전환해도 절대 무시되면 안 되는 로직은?

💡 해설: 안전 관련 로직은 자동/수동 모드와 무관하게 항상 최우선으로 적용되어야 합니다.

0. 자기유지회로를 이해하기 전에: 스위치의 물리적 원리

📌 핵심 용어

용어의미
순간접점(모멘터리) 버튼손을 떼면 원래 상태로 돌아오는 버튼(초인종형)
자기유지자기 자신의 보조접점으로 스스로 켜진 상태를 유지하는 것
인터록서로 동시에 켜지면 안 되는 두 출력을 막아주는 안전장치
여자(勵磁)코일에 전류가 흘러 코일이 '켜진' 상태가 되는 것

1. 순간접점 버튼이란

순간접점 버튼은 손을 떼면 원래대로 돌아오는 버튼으로, 초인종 버튼을 떠올리면 된다. 계속 누르고 있지 않으면 신호가 바로 끊긴다.

2. 그런데 왜 '자기유지'가 필요한가

순간접점 버튼만으로는 손을 떼는 순간 모터가 꺼져버린다. 버튼에서 손을 떼도 동작을 계속 유지하려면, 스스로 자기 자신을 붙잡아두는 회로가 필요하다.

3. 자기유지의 원리 아주 쉽게

코일이 켜지면 자신의 보조 접점도 같이 붙는데, 이 보조접점을 기동버튼과 병렬로 연결해두면 기동버튼에서 손을 떼도 이 보조접점을 통해 계속 전류가 흘러 스스로를 유지한다. 문을 열어두기 위해 문 밑에 버팀쇠를 괴어놓는 것과 비슷하다.

4. 정지는 왜 항상 직렬(B접점)로 넣는가

자기유지 회로를 끊으려면 전체 경로 중 어느 한 곳만 끊어도 된다. 정지버튼(B접점)을 자기유지 루프와 직렬로 넣어두면 그 버튼을 누르는 순간 전체 회로가 끊어져 확실하게 정지시킬 수 있다.

💡 실무 팁

자기유지회로는 PLC 래더의 가장 기본이자 실전 회로 대부분에 등장하는 핵심 패턴이므로, 손으로 직접 여러 번 그려보며 완전히 익혀두는 것이 좋다.
✏️ 단원 확인문제 (4문제)
점수: 0 / 100점 (정답 0 / 4문제)

Q1. 손을 떼면 원래 상태로 돌아오는 버튼을 무엇이라 하는가?

💡 해설: 초인종처럼 손을 떼면 원래 상태로 돌아오는 버튼을 순간접점(모멘터리) 버튼이라 합니다.

Q2. 자기 자신의 보조접점으로 스스로 켜진 상태를 유지하는 회로를 무엇이라 하는가? (한글 4글자)

💡 해설: 자기유지회로는 자신의 보조접점을 이용해 스스로 동작 상태를 유지합니다.

Q3. 정지버튼을 자기유지 회로에 넣을 때 일반적으로 사용하는 접점 방식은?
