실전 예제① 자기유지회로·인터록

📌 이 주제에서 만들어 볼 예제

가장 기본이 되는 자기유지회로와, 정회전/역회전처럼 서로 동시에 켜지면 안 되는 출력을 막는 인터록 회로 두 가지를 직접 구성해본다.

1. 자기유지회로란?

기동버튼(I0.0)을 눌렀다 떼면 보통 출력은 바로 꺼진다. 그런데 버튼을 떼도 스스로 통전 상태를 유지하도록 만든 것이 자기유지회로다. 방법은 간단하다 — 기동버튼(I0.0)과 병렬로, 출력 코일 자신의 A접점(Q0.0)을 추가해서, 한 번 출력이 켜지면 그 접점을 통해 스스로 전류 경로를 유지하게 만드는 것이다.

2. 자기유지회로 래더 예제

기동(I0.0) 또는 자기유지접점(Q0.0)이 통전되고, 정지(I0.1)가 눌리지 않은 상태에서 출력 코일 Q0.0이 ON — 대표적인 자기유지회로 구조

3. 회로 동작 순서

① I0.0(기동)을 누르면 Q0.0 ON → ② I0.0에서 손을 떼도 Q0.0의 A접점(자기유지접점)이 이미 통전 중이므로 회로가 유지 → ③ I0.1(정지, B접점)을 누르면 경로가 끊어져 Q0.0 OFF.

4. 인터록(Interlock) 회로란?

모터의 정회전(Q0.0)과 역회전(Q0.1)처럼 절대 동시에 켜지면 안 되는 두 출력이 있을 때, 서로 상대방 코일의 B접점을 자기 회로에 직렬로 넣어두는 방법이다.

5. 안전상 유의사항

래더 안에서의 인터록(전기적 인터록)만으로 안심하지 말고, 실제 현장에서는 정역회전 전자접촉기(MC) 사이에 기계적 인터록도 함께 적용하는 것이 일반적인 안전 설계 원칙이다.
✏️ 확인문제 (2문제)
점수: 0 / 100점 (정답 0 / 2문제)

Q1. 자기유지회로에서 기동버튼(I0.0)과 병렬로 연결해, 버튼을 떼어도 출력이 계속 유지되게 만드는 접점을 무엇이라 하는가? (한글) (단답형)

💡 해설: 출력 코일 자신의 A접점을 기동버튼과 병렬로 넣어 스스로 전류 경로를 유지시키는 것을 자기유지접점이라 합니다.

Q2. 정회전/역회전처럼 동시에 켜지면 안 되는 두 출력이 서로 상대방 코일의 B접점을 직렬로 넣어 막는 회로 구성 방식은?

💡 해설: 서로 상대방 출력의 B접점을 직렬로 넣어 동시 투입을 막는 방식을 인터록(Interlock)이라 합니다.
