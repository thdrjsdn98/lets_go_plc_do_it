필수 단축키와 화면 설정

📌 이 주제에서 다루는 내용

TIA Portal은 버전이 올라가면서 단축키가 여러 번 바뀐 이력이 있는 소프트웨어다. 그래서 ①어떤 프로그램에서도 통하는 공통 윈도우 단축키, ②TIA Portal 안에서 직접 확인·수정하는 방법 두 가지를 함께 익힌다.

1. 공통 윈도우 단축키 (TIA Portal · STEP 7 Classic 공통)

단축키기능
Ctrl + S프로젝트 저장
Ctrl + Z / Ctrl + Y실행 취소 / 다시 실행
Ctrl + C / Ctrl + V / Ctrl + X복사 / 붙여넣기 / 잘라내기
Delete선택한 요소(접점·코일·네트워크) 삭제
Ctrl + F현재 화면(태그·프로그램)에서 찾기
F1커서 위치 관련 도움말 열기
이 정도는 버전이 바뀌어도 대부분 그대로 유지되는 편이라 가장 먼저 손에 익혀두면 좋다.

2. TIA Portal 단축키를 '내 눈으로' 확인하는 방법 (가장 확실한 방법)

지멘스는 버전업마다 단축키를 자주 조정해왔기 때문에, 인터넷의 특정 버전 단축키표를 그대로 외우기보다는 내가 쓰는 버전에서 직접 확인하는 습관이 훨씬 안전하다.
메뉴에서 Options(옵션) → Settings(설정) → General(일반) → Keyboard shortcuts(키보드 단축키) 경로로 들어가면, 현재 설치된 버전에 적용된 모든 명령어별 단축키를 검색·확인하고, 원하는 조합으로 직접 재할당할 수도 있다.

3. 실무에서 자주 언급되는 조작들

아이콘 위에 마우스를 잠깐 올려두면(호버) 툴팁에 해당 기능의 단축키가 함께 표시되는 경우가 많으므로, 자주 쓰는 컴파일·다운로드·모니터링 아이콘부터 툴팁을 확인해보자. 또한 사용자들 사이에서 상호참조(Cross reference) 창을 여는 데 Shift + F11이 널리 쓰인다고 알려져 있다(버전에 따라 다를 수 있으니 2번 방법으로 재확인 권장).

4. STEP 7 Classic(SIMATIC Manager)과의 차이

STEP 7 Classic은 SIMATIC Manager라는 별도 창에서 프로젝트를 관리하고, LAD/STL/FBD 편집기가 각각 별도의 창으로 열린다는 점이 TIA Portal과 가장 큰 차이다. 공통 단축키는 통하지만, 컴파일·다운로드 관련 단축키는 두 프로그램이 서로 다르게 지정된 경우가 많다.
✏️ 확인문제 (2문제)
점수: 0 / 100점 (정답 0 / 2문제)

Q1. TIA Portal을 포함해 대부분의 윈도우 프로그램에서 공통으로 '실행 취소'에 쓰이는 단축키는?

💡 해설: Ctrl+Z는 실행 취소, Ctrl+Y는 다시 실행에 해당하는 범용 윈도우 단축키입니다.

Q2. 현재 설치된 TIA Portal 버전의 정확한 단축키 목록을 확인하거나 직접 바꾸려면 어느 메뉴로 들어가야 하는가?

💡 해설: 지멘스는 버전마다 기본 단축키를 여러 번 바꿔왔기 때문에, Options-Settings-General-Keyboard shortcuts 메뉴에서 현재 버전 기준으로 직접 확인하는 것이 가장 정확합니다.
