01. 왜 단축키 학습이 까다로운가

1. 자주 바뀌는 기본 단축키

지멘스 사용자 포럼에는 TIA Portal의 기본 단축키가 버전이 올라갈 때마다 여러 차례 바뀌었다는 불만이 실제로 여러 차례 제기되어 왔다. 그래서 특정 옛날 버전 기준의 단축키표를 그대로 외우는 것은 위험할 수 있다.

2. 이 강좌의 접근 방법

이 강좌에서는 ① 버전이 바뀌어도 잘 유지되는 공통 윈도우 단축키를 우선 익히고, ② TIA Portal 안에서 내가 쓰는 버전 기준으로 직접 확인하는 방법을 배우는 순서로 진행한다.

3. 단축키를 외우는 것보다 중요한 것

실무에서는 단축키를 몇 개 아는 것보다 필요한 기능을 언제든 메뉴나 우클릭으로 찾아낼 수 있는 감각이 훨씬 중요하다. 단축키는 이미 알고 있는 기능을 더 빠르게 실행하는 '지름길'일 뿐, 단축키를 모른다고 해서 그 기능을 아예 못 쓰는 것은 아니다.

4. 학습 순서 제안

① 이번 단원들에서 공통 단축키부터 익히고 → ② 실제로 TIA Portal을 열어 Options 메뉴에서 내 버전의 단축키를 한 번 훑어보고 → ③ 자주 쓰는 3~4개만 우선 손에 익히는 순서를 추천한다.
✏️ 단원 확인문제 (4문제)
점수: 0 / 100점 (정답 0 / 4문제)

Q1. TIA Portal 단축키에 대한 설명으로 옳은 것은?

💡 해설: 지멘스 사용자 포럼에는 TIA Portal 단축키가 버전업마다 여러 번 바뀌었다는 불만이 실제로 여러 차례 제기되었습니다.

Q2. 단축키를 안전하게 확인하는 가장 좋은 방법은?

💡 해설: 버전마다 단축키가 다를 수 있으므로, 실제 설치된 버전의 설정 화면에서 직접 확인하는 것이 가장 정확합니다.

Q3. 단축키에 대한 설명 중 가장 적절한 것은?

💡 해설: 단축키는 메뉴나 우클릭으로도 실행 가능한 기능을 더 빠르게 실행하는 지름길에 불과합니다.

Q4. 이 강좌가 추천하는 단축키 학습 순서로 가장 적절한 것은?

💡 해설: 공통 단축키를 먼저 익히고, 내 버전에서 직접 확인한 뒤, 자주 쓰는 몇 개부터 손에 익히는 순서를 추천합니다.

02. 파일·프로젝트 관련 공통 단축키

1. 저장 관련

단축키기능
Ctrl + S현재 프로젝트 저장
Ctrl + P인쇄 대화상자 열기
대부분의 윈도우 프로그램과 동일하게 동작하는 공통 단축키다.

2. 습관화 팁

작업 중간중간 Ctrl+S를 누르는 습관만 들여도, 정전이나 프로그램 오류로 인한 작업 손실을 크게 줄일 수 있다.

3. 자동 저장 기능도 함께 활용

TIA Portal은 일정 주기로 자동 저장(Autosave) 옵션을 제공하는 경우가 많다. 수동 저장 습관과 자동 저장 옵션을 함께 활용하면 작업 손실 위험을 이중으로 줄일 수 있다.

4. 인쇄 활용 팁

프로그램 전체를 인쇄하기보다는, 필요한 네트워크(rung)만 선택해서 인쇄하거나 PDF로 내보내면 검토용 자료를 훨씬 깔끔하게 만들 수 있다.
✏️ 단원 확인문제 (4문제)
점수: 0 / 100점 (정답 0 / 4문제)

Q1. 프로젝트/파일 저장에 쓰이는 공통 단축키는?

💡 해설: Ctrl+S는 대부분의 윈도우 프로그램과 마찬가지로 저장에 사용됩니다.

Q2. 인쇄 대화상자를 여는 데 널리 쓰이는 공통 단축키는?

💡 해설: Ctrl+P는 대부분의 윈도우 프로그램에서 인쇄 대화상자를 여는 공통 단축키입니다.

Q3. 수동 저장 습관과 함께 활용하면 좋은 기능은?

💡 해설: 자동 저장 옵션을 함께 활용하면 수동 저장을 깜빡했을 때도 작업 손실을 줄일 수 있습니다.

Q4. 검토용 자료를 깔끔하게 만들려면 인쇄 시 어떻게 하는 것이 좋은가?

💡 해설: 필요한 부분만 선택해 인쇄하거나 PDF로 내보내면 훨씬 깔끔한 검토 자료를 만들 수 있습니다.

03. 편집 관련 단축키

1. 실행취소/복사/붙여넣기

단축키기능
Ctrl + Z / Ctrl + Y실행 취소 / 다시 실행
Ctrl + C / Ctrl + V / Ctrl + X복사 / 붙여넣기 / 잘라내기
Delete선택한 접점·코일·네트워크 삭제
Ctrl + A현재 화면의 전체 선택

2. 실무 활용 팁

비슷한 네트워크(rung)를 여러 개 만들어야 할 때, 하나를 완성한 뒤 복사→붙여넣기로 틀을 재사용하고 주소만 바꾸면 작업 속도가 크게 빨라진다.

3. 실행취소의 한계

Ctrl+Z(실행취소)는 대체로 여러 단계를 되돌릴 수 있지만, 저장 후에는 되돌릴 수 있는 범위가 제한될 수 있다. 큰 수정을 하기 전에는 먼저 저장을 해두고 시작하는 것이 안전하다.

4. 삭제 시 주의사항

Delete로 접점이나 코일을 지울 때, 해당 태그가 다른 네트워크에서도 쓰이고 있다면 상호참조(Cross reference)를 먼저 확인해 영향 범위를 파악하는 것이 안전하다.
✏️ 단원 확인문제 (4문제)
점수: 0 / 100점 (정답 0 / 4문제)

Q1. 실행취소의 반대(다시 실행)에 쓰이는 단축키는?

💡 해설: Ctrl+Z는 실행 취소, Ctrl+Y는 다시 실행에 해당합니다.

Q2. 현재 화면의 모든 항목을 선택하는 공통 단축키는?

💡 해설: Ctrl+A는 대부분의 윈도우 프로그램에서 전체 선택에 사용되는 공통 단축키입니다.

Q3. 큰 수정을 하기 전 안전을 위해 먼저 해두면 좋은 습관은?

💡 해설: 실행취소가 항상 완벽하게 되돌려주지 않을 수 있으므로, 큰 수정 전에는 먼저 저장해두는 것이 안전합니다.

Q4. 특정 태그를 삭제하기 전에 영향 범위를 파악하려면 무엇을 확인하는 것이 좋은가?

💡 해설: 상호참조를 확인하면 해당 태그가 다른 네트워크에서도 쓰이고 있는지 미리 파악할 수 있습니다.

04. 찾기·바꾸기와 상호참조

1. 찾기

Ctrl + F는 현재 화면(태그표, 프로그램 등)에서 원하는 텍스트나 주소를 찾을 때 쓰이는 공통 단축키다.

2. 상호참조(Cross reference)

특정 태그나 블록이 프로그램 전체 어디서 쓰이는지 한눈에 보여주는 상호참조 창을 여는 데, 사용자들 사이에서 Shift + F11이 널리 쓰인다고 알려져 있다(버전에 따라 다를 수 있으므로 실제 설치 버전에서 재확인 권장).

3. 상호참조가 중요한 이유

여러 사람이 함께 작업하거나 프로그램이 커질수록, 특정 태그를 수정하기 전에 그 태그가 몇 개의 네트워크에서 쓰이고 있는지 미리 확인하는 습관이 예상치 못한 오작동을 막아준다.

4. 찾기 범위 설정

찾기 기능은 보통 현재 열린 블록 안에서만 찾는 것과, 프로젝트 전체에서 찾는 것을 구분해서 지원한다. 프로젝트 규모가 크다면 전체 프로젝트 검색 옵션을 활용하는 것이 효율적이다.
✏️ 단원 확인문제 (4문제)
점수: 0 / 100점 (정답 0 / 4문제)

Q1. 현재 화면에서 특정 태그·텍스트를 찾을 때 쓰는 공통 단축키는?

💡 해설: Ctrl+F는 대부분의 윈도우 프로그램에서 찾기에 사용되는 공통 단축키입니다.

Q2. 사용자들 사이에서 상호참조(Cross reference) 창을 여는 데 널리 쓰인다고 알려진 단축키는? (단답형)

💡 해설: 지멘스 포럼 등에서 Shift+F11이 상호참조 창을 여는 단축키로 자주 언급됩니다(버전별 재확인 권장).

Q3. 상호참조를 미리 확인하는 것이 중요한 이유는?

💡 해설: 상호참조로 특정 태그가 몇 개의 네트워크에서 쓰이는지 미리 확인하면 예상치 못한 오작동을 막을 수 있습니다.

Q4. 프로젝트 규모가 클 때 특정 태그를 효율적으로 찾으려면?

💡 해설: 전체 프로젝트 검색 옵션을 활용하면 여러 블록에 걸쳐 있는 태그도 한 번에 찾을 수 있습니다.

05. 보기(뷰) 관련 조작

1. 확대/축소

대부분의 윈도우 프로그램처럼 Ctrl + 마우스 휠로 작업영역을 확대·축소할 수 있는 경우가 많다.

2. 창 전환

여러 개의 도킹된 창(뷰)을 순서대로 전환할 때, 윈도우 프로그램 전반에서 Ctrl + Tab이 널리 쓰인다.

3. 창 도킹/분리

태스크카드나 인스펙터 창 등 대부분의 패널은 드래그해서 위치를 바꾸거나(도킹), 화면 밖으로 완전히 분리해 별도 창처럼 띄울 수도 있다. 듀얼 모니터 환경이라면 프로그램 에디터와 태그표를 각각 다른 모니터에 띄워두는 방식도 유용하다.

4. 화면 배치 초기화

이것저것 옮기다 화면이 뒤죽박죽되었다면, 보기(View) 메뉴에서 기본 배치로 초기화하는 옵션을 찾아 원래 상태로 되돌릴 수 있다.
✏️ 단원 확인문제 (4문제)
점수: 0 / 100점 (정답 0 / 4문제)

Q1. 대부분의 윈도우 프로그램에서 화면을 확대/축소할 때 자주 쓰이는 조합은?

💡 해설: Ctrl + 마우스 휠은 다수의 윈도우 프로그램에서 화면 확대/축소에 널리 쓰이는 조합입니다.

Q2. 여러 개의 열린 창(도킹된 뷰)을 순서대로 전환할 때 널리 쓰이는 윈도우 공통 단축키는?

💡 해설: Ctrl + Tab은 여러 창/탭을 순서대로 전환하는 데 널리 쓰이는 윈도우 공통 단축키입니다.

Q3. 태스크카드나 인스펙터 창처럼 위치를 바꾸거나 분리할 수 있는 것을 무엇이라 하는가?

💡 해설: 대부분의 패널은 도킹(위치 이동) 및 화면 밖 분리가 가능한 도킹 패널로 구성되어 있습니다.

Q4. 화면 배치가 뒤죽박죽되었을 때 되돌릴 수 있는 방법은?

💡 해설: 보기(View) 메뉴의 초기화 옵션으로 화면 배치를 기본 상태로 되돌릴 수 있습니다.

06. 컴파일·다운로드 관련 조작

1. 우클릭 메뉴 활용

컴파일·다운로드처럼 버전에 따라 단축키가 자주 바뀌는 기능은, 단축키를 외우기보다 프로젝트 트리에서 디바이스를 우클릭해 나오는 메뉴(Compile/Download)를 사용하는 것이 가장 안전하다.

2. 툴팁으로 확인하기

툴바 아이콘 위에 마우스를 잠깐 올려두면(호버) 툴팁(Tooltip)에 기능 이름과 함께 현재 버전에서의 단축키가 표시되는 경우가 많다.

3. 부분 컴파일 vs 전체 컴파일

블록을 하나만 수정했다면 해당 블록만 컴파일해서 시간을 절약할 수 있고, 구조를 크게 바꿨다면 하드웨어와 소프트웨어 전체를 컴파일하는 옵션을 선택하는 것이 안전하다.

4. 다운로드 옵션 확인

다운로드 시 나타나는 옵션 중 '차이만 다운로드(변경분만)'와 '전체 다운로드'를 구분해서 제공하는 경우가 있다. 시간이 급할 땐 전자가 빠르지만, 문제가 의심될 땐 전체 다운로드로 확실하게 갱신하는 편이 안전하다.
✏️ 단원 확인문제 (4문제)
점수: 0 / 100점 (정답 0 / 4문제)

Q1. 컴파일·다운로드처럼 버전마다 단축키가 바뀔 수 있는 기능을 안전하게 실행하는 방법은?

💡 해설: 단축키 대신 우클릭 메뉴를 사용하면 버전에 관계없이 안전하게 같은 기능을 실행할 수 있습니다.

Q2. 툴바 아이콘에 마우스를 잠깐 올려두면 나타나는, 단축키 정보가 포함된 요소는?

💡 해설: 툴팁(Tooltip)에는 기능 설명과 함께 해당 버전의 단축키 정보가 표시되는 경우가 많습니다.

Q3. 블록 하나만 수정했을 때 시간을 절약하는 방법은?

💡 해설: 수정한 블록만 컴파일하면 전체를 컴파일하는 것보다 시간을 절약할 수 있습니다.

Q4. 문제가 의심될 때 확실하게 갱신하려면 어떤 다운로드 방식이 안전한가?

💡 해설: 문제가 의심될 때는 변경분만 다운로드하는 것보다 전체 다운로드로 확실하게 갱신하는 것이 안전합니다.

07. 단축키 커스터마이징

1. 설정 경로

메뉴에서 Options(옵션) → Settings(설정) → General(일반) → Keyboard shortcuts(키보드 단축키)로 들어가면, 현재 설치된 버전의 모든 명령어별 단축키를 검색·확인할 수 있다.

2. 직접 재할당하기

원하는 기능을 검색해 찾은 뒤, 내가 자주 쓰는 키 조합으로 직접 재할당할 수 있다. 이때 다른 기능과 중복되지 않는지 함께 확인하는 것이 중요하다.

3. 실전 팁

모든 단축키를 다 외우려 하지 말고, 내가 하루에도 여러 번 쓰는 3~4개(예: 저장, 찾기, 컴파일 관련 메뉴)부터 먼저 손에 익히는 것을 추천한다.

4. 나만의 단축키표 만들기

직접 재할당한 단축키들은 캡처해두거나 메모장에 정리해서 나만의 단축키표로 보관해두면, 다른 PC에 새로 설치했을 때도 빠르게 같은 환경을 만들 수 있다.
✏️ 단원 확인문제 (4문제)
점수: 0 / 100점 (정답 0 / 4문제)

Q1. TIA Portal에서 직접 단축키를 지정/변경할 수 있는 메뉴 경로는?

💡 해설: 이 경로에서 현재 버전의 단축키를 검색·확인하고 직접 재할당할 수 있습니다.

Q2. 단축키를 새로 등록할 때 함께 확인해야 할 것으로 가장 적절한 것은?

💡 해설: 새 단축키가 이미 다른 기능에 쓰이고 있지는 않은지 확인해야 오작동을 피할 수 있습니다.

Q3. 단축키를 얼마나 외워야 효율적인가?

💡 해설: 모든 단축키를 외우기보다 자주 쓰는 몇 개부터 우선 익히는 것이 효율적입니다.

Q4. 직접 재할당한 단축키를 다른 PC에서도 빠르게 재현하려면?

💡 해설: 직접 재할당한 단축키를 정리해두면 다른 PC에서도 빠르게 같은 환경을 재현할 수 있습니다.

08. STEP 7 Classic과의 차이 + 생산성 팁

1. SIMATIC Manager 구조

STEP 7 Classic은 SIMATIC Manager라는 별도 창에서 프로젝트를 관리하고, LAD/STL/FBD 편집기가 각각 별도의 창(프로그램)으로 열린다는 점이 TIA Portal(하나의 창 안에서 모든 뷰 전환)과 가장 큰 차이다.

2. 즐겨찾기(Favorites) 활용

TIA Portal 태스크카드의 즐겨찾기(Favorites) 영역에 자주 쓰는 명령어(접점, 코일, 타이머 등)를 등록해두면, 명령어 목록을 매번 뒤지지 않고 빠르게 드래그해서 쓸 수 있다.

3. 마우스 제스처 활용

네트워크(rung) 사이를 마우스 오른쪽 버튼 클릭만으로 삽입·삭제·주석추가 등 다양한 조작을 할 수 있는 우클릭 컨텍스트 메뉴를 적극 활용하면, 단축키를 몰라도 웬만한 작업은 충분히 빠르게 처리할 수 있다.

4. 템플릿/복사 활용한 생산성 향상

자주 쓰는 로직 패턴(예: 자기유지+인터록 조합)을 미리 만들어두고, 새 프로젝트마다 복사해서 재사용하면 매번 처음부터 작성하는 것보다 훨씬 빠르게 개발할 수 있다.
✏️ 단원 확인문제 (4문제)
점수: 0 / 100점 (정답 0 / 4문제)

Q1. STEP 7 Classic에서 프로젝트를 관리하는 별도의 프로그램(창) 이름은?

💡 해설: STEP 7 Classic은 SIMATIC Manager라는 별도 프로그램에서 프로젝트를 관리합니다.

Q2. 자주 쓰는 명령어를 모아두고 빠르게 드래그해서 쓸 수 있게 해주는 태스크카드 영역은?

💡 해설: 즐겨찾기(Favorites)에 자주 쓰는 명령어를 등록해두면 작업 속도를 높일 수 있습니다.

Q3. 단축키를 몰라도 웬만한 작업을 빠르게 처리할 수 있게 해주는 방법은?

💡 해설: 우클릭 컨텍스트 메뉴를 적극 활용하면 단축키를 몰라도 대부분의 조작을 빠르게 처리할 수 있습니다.

Q4. 자주 쓰는 로직 패턴을 여러 프로젝트에서 빠르게 재사용하는 방법은?

💡 해설: 자주 쓰는 패턴을 템플릿처럼 만들어두고 복사해서 재사용하면 개발 속도를 크게 높일 수 있습니다.
