래더(LAD) 기초 명령어

📌 이 주제의 핵심 용어

명령어의미
A접점(NO)평상시 열림, 조건이 참이면 닫혀(통전) 신호를 전달
B접점(NC)평상시 닫힘, 조건이 참이면 열려(차단) 신호를 끊음
코일 ( = )조건이 참인 동안만 출력을 ON
SET(S) / RESET(R)한 번 켜면(또는 끄면) 반대 명령이 올 때까지 상태 유지
TON / TOF / TP온딜레이 / 오프딜레이 / 펄스 타이머
CTU / CTD / CTUD업카운터 / 다운카운터 / 업다운카운터

1. 접점 - A접점 / B접점

래더의 가장 기본 단위는 접점이다. A접점(Normally Open)은 평소엔 끊어져 있다가 해당 비트가 1이 되면 통전되고, B접점(Normally Closed)은 평소엔 통전되어 있다가 해당 비트가 1이 되면 끊어진다.

2. 코일과 SET/RESET

일반 코일(=)은 앞의 조건이 참인 그 스캔 동안만 출력이 ON되고 조건이 꺼지면 즉시 OFF된다. 반면 SET(S) 코일은 한 번 조건이 참이 되면 이후 조건이 꺼져도 출력이 계속 ON 상태를 유지하며, RESET(R) 명령이 실행되어야 비로소 OFF된다.

3. 타이머 - TON / TOF / TP

TON(On-Delay): 입력이 ON된 후 설정 시간이 지나야 출력이 ON. TOF(Off-Delay): 입력이 OFF된 후 설정 시간이 지나야 출력이 OFF. TP(Pulse): 입력이 ON되는 순간 설정 시간만큼만 출력이 ON.

4. 카운터 - CTU / CTD / CTUD

CTU(Up Counter): CU 입력이 켜질 때마다 카운트 값이 1씩 증가, 설정값(PV) 도달 시 출력 ON. CTD(Down Counter): CD 입력마다 1씩 감소, 0이 되면 출력 ON. CTUD: 증가·감소를 모두 지원.

5. 비교·이동 명령

CMP(비교): 두 값을 ==, >, < 등으로 비교. MOVE: 한 주소의 값을 다른 주소로 복사. 데이터 타입은 Bool(0/1), Int/DInt(정수), Real(실수) 정도만 우선 구분해도 충분하다.
✏️ 확인문제 (2문제)
점수: 0 / 100점 (정답 0 / 2문제)

Q1. 입력 조건이 ON된 뒤 설정 시간이 지나야 출력이 ON되는 타이머는?

💡 해설: TON(On-Delay Timer)은 입력이 켜진 뒤 설정 시간만큼 지연되어 출력이 켜지는 온딜레이 타이머입니다.

Q2. 한 번 ON되면 RESET(R) 명령이 실행되기 전까지 계속 ON 상태를 유지하는 출력 명령은?

💡 해설: SET(S) 코일은 조건이 한 번 참이 되면 이후 조건이 꺼져도 RESET(R)이 실행되기 전까지 출력을 계속 ON으로 유지합니다.
