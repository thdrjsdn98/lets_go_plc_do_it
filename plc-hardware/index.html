01. CPU 종류와 선택 기준

📌 핵심 CPU 계열

계열특징
S7-1200엔트리~미들레인지, 소규모 자동화에 적합
S7-1500고성능, 대규모 설비·모션제어에 적합
S7-300/400레거시(구형) CPU, 주로 STEP 7 Classic 사용

1. 선택 기준

필요한 I/O 점수, 통신 포트 수, 연산 속도, 프로그램/데이터 메모리 용량을 먼저 파악한 뒤 이를 만족하는 CPU 모델을 고른다.

2. 확장성 고려

설비가 향후 커질 가능성이 있다면, 처음부터 I/O 확장 슬롯과 통신 포트가 넉넉한 상위 모델을 선택하는 것이 유지보수에 유리하다.
✏️ 단원 확인문제 (2문제)
점수: 0 / 100점 (정답 0 / 2문제)

Q1. 고성능·대규모 설비에 주로 사용되는 최신 지멘스 CPU 계열은?

💡 해설: S7-1500은 고성능이 필요한 대규모 설비나 모션제어에 주로 사용됩니다.

Q2. 소규모 자동화 설비에 적합한 엔트리급 최신 CPU 계열은?

💡 해설: S7-1200은 엔트리~미들레인지급으로 소규모 자동화 설비에 적합합니다.

02. 디바이스 추가와 하드웨어 카탈로그

1. 하드웨어 카탈로그

우측 태스크카드의 하드웨어 카탈로그에서 CPU, I/O 모듈, 통신 모듈 등을 검색·필터링해 찾을 수 있다.

2. 슬롯 배치 규칙

CPU 옆 슬롯부터 순서대로 모듈을 배치해야 하며, 모델별로 확장 가능한 슬롯 수와 위치에 제한이 있으므로 매뉴얼상의 배치 규칙을 따라야 한다.

3. 검색 팁

정확한 주문번호를 모른다면 CPU 라벨의 문자를 카탈로그 검색창에 입력해 필터링하는 방식으로 빠르게 찾을 수 있다.
✏️ 단원 확인문제 (2문제)
점수: 0 / 100점 (정답 0 / 2문제)

Q1. 디바이스 추가시 실물 CPU와 반드시 일치시켜야 하는 항목은? (한글) (단답형)

💡 해설: 실제 CPU의 정확한 주문번호를 그대로 선택해야 다운로드시 오류가 발생하지 않습니다.

Q2. CPU 옆에 입출력 모듈을 추가할 때 참고하는 창은?

💡 해설: 하드웨어 카탈로그에서 필요한 I/O 모듈, 통신 모듈 등을 검색해 배치할 수 있습니다.

03. I/O 어드레싱 체계

📌 핵심 용어

기호의미
%I입력(Input) - 버튼, 센서 등 외부 신호가 들어오는 주소
%Q출력(Output) - 램프, 모터 등 외부로 나가는 신호 주소
%M내부 메모리 비트 - PLC 내부에서만 쓰는 임시 신호
%DB데이터 블록 - 변수·설정값을 구조적으로 저장

1. 비트·바이트·워드 표기

I0.0은 입력 0바이트의 0번 비트를 뜻하며, I0.0~I0.7을 묶어 IB0(바이트), 두 바이트를 묶으면 IW0(워드)로 표기한다. 출력(Q)과 메모리(M)도 동일한 표기 규칙을 따른다.
✏️ 단원 확인문제 (2문제)
점수: 0 / 100점 (정답 0 / 2문제)

Q1. I0.0, I0.1 ... I0.7을 묶어서 부르는 바이트 단위 표기는?

💡 해설: I0.0~I0.7 8개의 비트를 묶은 바이트 단위 표기는 IB0입니다.

Q2. 외부로 나가는 출력 신호(램프, 모터 등)에 사용하는 어드레스 접두사는?

💡 해설: %Q는 출력(Output), %I는 입력(Input)에 사용하는 어드레스 접두사입니다.

04. PG/PC 인터페이스와 온라인 액세스

1. 온라인 액세스 설정

PC와 PLC를 연결하려면 온라인 액세스(Online access) 메뉴에서 실제로 케이블이 꽂힌 네트워크 어댑터를 선택해야 한다.

2. 통신 방식

요즘 CPU는 대부분 PROFINET(이더넷) 방식으로 연결하며, PC의 IP 대역과 CPU의 IP 주소가 같은 서브넷에 있어야 정상적으로 통신된다.
✏️ 단원 확인문제 (2문제)
점수: 0 / 100점 (정답 0 / 2문제)

Q1. PC와 PLC를 실제로 연결하기 위해 선택해야 하는 설정은?

💡 해설: 실제로 케이블이 꽂힌 네트워크 어댑터를 온라인 액세스에서 선택해야 통신이 가능합니다.

Q2. 최신 지멘스 CPU가 PC와 통신할 때 주로 사용하는 물리적 연결 방식은?

💡 해설: 요즘 CPU는 대부분 PROFINET(이더넷) 방식으로 PC와 통신합니다.

05. IP 주소·서브넷 설정

1. IP 주소 지정

하드웨어 구성 화면에서 CPU를 클릭하면 인스펙터 창의 속성(Properties) → 일반(General) → 이더넷 주소에서 IP 주소·서브넷 마스크를 지정할 수 있다.

2. 주소 충돌 주의

같은 네트워크에 여러 CPU가 있다면 서로 겹치지 않는 IP를 부여해야 하며, 충돌 시 통신 오류나 다운로드 실패가 발생할 수 있다.
✏️ 단원 확인문제 (2문제)
점수: 0 / 100점 (정답 0 / 2문제)

Q1. CPU의 IP주소를 설정하는 위치는?

💡 해설: 인스펙터 창의 속성(Properties) 탭 안 이더넷 주소 항목에서 IP주소를 설정합니다.

Q2. 같은 네트워크의 여러 CPU에 절대 겹치면 안 되는 값은?

💡 해설: 같은 네트워크 안의 여러 CPU는 서로 다른 IP 주소를 가져야 통신 충돌이 발생하지 않습니다.

06. PROFINET / PROFIBUS 네트워크 개요

1. PROFINET

이더넷 기반의 최신 지멘스 산업용 통신 프로토콜로, 실시간성을 지원하며 S7-1200/1500에서 표준으로 사용된다.

2. PROFIBUS

주로 S7-300/400 세대와 함께 쓰이던 구형 시리얼 기반 필드버스로, 최근에는 PROFINET으로 전환되는 추세다.
✏️ 단원 확인문제 (2문제)
점수: 0 / 100점 (정답 0 / 2문제)

Q1. 이더넷 기반의 최신 지멘스 산업용 통신 프로토콜은?

💡 해설: PROFINET은 이더넷 기반의 최신 산업용 통신 프로토콜로 실시간성을 지원합니다.

Q2. 주로 S7-300/400 세대와 함께 쓰이던 구형 시리얼 기반 필드버스는?

💡 해설: PROFIBUS는 S7-300/400 세대에서 널리 쓰이던 구형 시리얼 기반 필드버스입니다.

07. 다운로드와 하드웨어 불일치 문제

1. 흔한 오류 원인

다운로드시 '하드웨어 불일치' 오류는 프로젝트에 설정된 CPU 주문번호나 펌웨어 버전이 실제 CPU와 다를 때 자주 발생한다.

2. 해결 방법

온라인 진단(Online & Diagnostics)에서 실제 연결된 CPU의 주문번호·펌웨어 버전을 확인한 뒤, 프로젝트의 하드웨어 구성과 대조해 일치시킨다.
✏️ 단원 확인문제 (2문제)
점수: 0 / 100점 (정답 0 / 2문제)

Q1. 다운로드시 '하드웨어 불일치' 오류가 자주 발생하는 원인은?

💡 해설: 프로젝트에 설정된 CPU 정보와 실제 하드웨어가 일치하지 않을 때 하드웨어 불일치 오류가 발생합니다.

Q2. 실제 연결된 CPU의 정보(주문번호, 펌웨어 등)를 확인할 수 있는 기능은?

💡 해설: 온라인 진단(Online & Diagnostics) 기능으로 실제 연결된 CPU의 상세 정보를 확인할 수 있습니다.

08. PLCSIM 시뮬레이션 활용

1. PLCSIM이란

지멘스가 제공하는 PLCSIM(S7-PLCSIM) 시뮬레이터는 실제 CPU 없이도 PC 안에 가상 CPU를 만들어 프로그램을 다운로드·테스트할 수 있게 해준다.

2. 활용 방법

PLCSIM에서는 와치 테이블(Watch table)을 이용해 특정 입력 비트를 강제로 On/Off 시켜가며, 실제 배선 없이도 로직이 의도대로 동작하는지 검증할 수 있다.

3. PLCSIM Advanced

더 고급 기능이 필요하다면 PLCSIM Advanced를 통해 가상 네트워크 통신, API 연동 등 확장된 시뮬레이션 환경을 사용할 수도 있다.
✏️ 단원 확인문제 (2문제)
점수: 0 / 100점 (정답 0 / 2문제)

Q1. 실제 하드웨어 없이 PC에서 가상 CPU를 만들어 테스트하는 지멘스 시뮬레이터 이름은? (영문) (단답형)

💡 해설: PLCSIM(S7-PLCSIM)은 실제 CPU 없이도 PC에서 가상 CPU를 만들어 프로그램을 테스트할 수 있는 지멘스의 시뮬레이터입니다.

Q2. PLCSIM/실제 PLC 모두에서 특정 비트 값을 강제로 켜고 끄며 로직을 확인할 때 사용하는 도구는?

💡 해설: 와치 테이블(Watch table)을 사용하면 특정 비트를 강제로 On/Off하며 로직 동작을 확인할 수 있습니다.
