하드웨어 구성과 통신 설정

📌 이 주제의 핵심 용어

기호의미
%I (I0.0 등)입력(Input) - 버튼, 센서 등 외부 신호가 들어오는 주소
%Q (Q0.0 등)출력(Output) - 램프, 모터 등 외부로 나가는 신호 주소
%M (M0.0 등)내부 메모리 비트 - PLC 내부에서만 쓰는 임시 신호
%DB데이터 블록 - 변수·설정값을 구조적으로 저장하는 메모리 영역

1. 디바이스(CPU) 추가하기

프로젝트 트리에서 '새 디바이스 추가'를 선택하면 CPU 목록이 뜬다. 이때 실제 PLC 본체 옆면에 붙은 정확한 주문번호(order number)와 펌웨어 버전을 그대로 선택해야 한다. 대충 비슷한 모델을 고르면 다운로드 단계에서 하드웨어 불일치 오류가 발생할 수 있다.

2. 통신(PG/PC 인터페이스) 설정

PC와 PLC를 연결하려면 온라인 액세스(Online access) 메뉴에서 실제로 케이블이 꽂힌 네트워크 어댑터를 선택해야 한다. 요즘 CPU는 대부분 PROFINET(이더넷) 방식이라, PC의 IP 대역과 CPU에 설정한 IP 주소가 같은 서브넷에 있어야 통신이 된다.

3. IP 주소와 서브넷 설정

하드웨어 구성 화면에서 CPU를 클릭하면 인스펙터 창의 속성(Properties) → 일반(General) → 이더넷 주소에서 IP 주소·서브넷 마스크를 지정할 수 있다.

4. I/O 주소 체계 정리

외부 리밋스위치·푸시버튼처럼 PLC 안으로 들어오는 신호는 %I, 램프·모터 접촉기처럼 PLC에서 밖으로 나가는 신호는 %Q로 표시한다. 프로그램 안에서만 쓰는 임시 신호는 %M, 설정값·레시피처럼 구조화된 데이터는 %DB(데이터블록)에 저장한다.

5. 다운로드와 PLCSIM 시뮬레이션

프로그램 작성 후 컴파일(Compile) → 다운로드(Download) → CPU를 RUN 모드로 전환하면 실제 동작을 시작한다. 실습용 PLC가 없다면, 지멘스가 제공하는 PLCSIM(S7-PLCSIM) 시뮬레이터에 프로그램을 다운로드해 하드웨어 없이도 로직을 검증할 수 있다.
✏️ 확인문제 (2문제)
점수: 0 / 100점 (정답 0 / 2문제)

Q1. 리밋스위치, 푸시버튼처럼 PLC로 들어오는 외부 입력 신호에 사용하는 어드레스 접두사는?

💡 해설: %I는 입력(Input), %Q는 출력(Output), %M은 내부 메모리 비트, %DB는 데이터블록입니다.

Q2. 실제 PLC 하드웨어 없이도 프로그램 동작을 테스트할 수 있는 지멘스의 시뮬레이션 소프트웨어 이름은? (영문) (단답형)

💡 해설: PLCSIM(S7-PLCSIM)은 실제 CPU 없이도 PC에서 가상 CPU를 만들어 프로그램을 다운로드·테스트할 수 있는 지멘스의 시뮬레이터입니다.
