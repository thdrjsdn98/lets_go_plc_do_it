01. 온딜레이 타이머 기본 예제

1. 예제 상황

버튼(I0.0)을 누르면 3초 뒤에 램프(Q0.0)가 켜지는 회로를 만든다고 하자. I0.0을 TON의 입력(IN)에 연결하고 설정시간(PT)에 3초를 입력한 뒤, 타이머의 출력(Q)을 램프 코일에 연결하면 된다.

2. 입력이 중간에 꺼지면?

설정시간이 지나기 전에 입력(I0.0)이 꺼지면, TON의 경과시간(경과된 카운트)은 리셋(초기화)되어 다시 처음부터 세야 한다.

3. 여러 타이머를 함께 쓸 때 주의점

같은 프로그램 안에서 여러 개의 TON을 사용할 때는, 각 타이머마다 서로 다른 타이머 인스턴스(DB)를 지정해야 한다. 실수로 같은 타이머를 두 곳에서 같이 쓰면 서로의 동작에 영향을 주어 예상치 못한 결과가 나올 수 있다.

4. 응용 - 경고 후 기동

버튼을 누르면 먼저 경고음(부저)이 3초간 울리고, 그 후에 실제로 설비가 기동되는 안전 절차를 TON 하나로 간단히 구현할 수 있다. 부저는 버튼과 동시에 켜고, 설비 기동은 TON의 출력 신호로 연결하면 된다.
✏️ 단원 확인문제 (4문제)
점수: 0 / 100점 (정답 0 / 4문제)

Q1. 입력이 켜진 뒤 지정시간 후 출력이 켜지는 예제에 적합한 타이머는?

💡 해설: TON(On-Delay)은 입력이 켜진 뒤 설정시간이 지나야 출력이 켜지는 타이머입니다.

Q2. TON의 설정시간이 지나기 전 입력이 꺼지면 타이머 경과시간은 어떻게 되는가? (한글로 간단히) (단답형)

💡 해설: TON은 설정시간이 지나기 전에 입력이 꺼지면 경과시간이 리셋(초기화)됩니다.

Q3. 여러 개의 TON을 사용할 때 각각 지정해야 하는 것은?

💡 해설: 각 TON마다 별도의 인스턴스를 지정하지 않으면 서로 영향을 주어 오작동할 수 있습니다.

Q4. 버튼을 누르면 경고음이 먼저 울리고 일정 시간 뒤 설비가 기동되게 하려면?

💡 해설: 부저를 버튼과 동시에 켜고, 설비 기동 신호를 TON의 지연된 출력으로 연결하면 경고 후 기동 절차를 구현할 수 있습니다.

02. 오프딜레이 타이머 예제

1. 예제 상황

사람이 방을 나가도 일정 시간 조명이 켜져 있다가 꺼지게 하고 싶다면 TOF를 사용한다. 스위치가 꺼지는 순간부터 시간을 세기 시작해, 설정시간이 지나야 램프가 꺼진다.

2. TOF의 즉시 ON 특성

TOF 타이머는 입력이 켜지는 순간 출력이 즉시 ON된다는 점을 기억해야 한다. 지연은 오직 '꺼질 때'만 적용된다.

3. 응용 - 모터 냉각팬 지연 정지

모터를 구동하는 인버터는 모터가 멈춘 직후에도 내부 발열이 남아있어, 냉각팬을 몇 분 더 돌려야 하는 경우가 많다. 모터 정지 신호를 TOF의 입력에 연결하고, TOF 출력을 냉각팬에 연결하면 이 요구사항을 간단히 구현할 수 있다.

4. TON과 TOF를 함께 쓰는 예

설비가 켜질 때는 TON으로 천천히 예열시키고, 꺼질 때는 TOF로 천천히 냉각시키는 식으로, 하나의 설비에 기동은 TON, 정지는 TOF를 동시에 적용하는 경우도 실무에서 흔하다.
✏️ 단원 확인문제 (4문제)
점수: 0 / 100점 (정답 0 / 4문제)

Q1. 스위치를 꺼도 일정시간 출력이 유지되다 꺼지는 예제에 적합한 타이머는?

💡 해설: TOF(Off-Delay)는 입력이 꺼진 뒤 설정시간이 지나야 출력이 꺼지는 타이머입니다.

Q2. TOF 타이머는 입력이 켜지는 순간 출력이 어떻게 되는가?

💡 해설: TOF는 입력이 켜지는 순간 출력이 즉시 ON되고, 지연은 입력이 꺼질 때만 적용됩니다.

Q3. 모터가 멈춘 뒤에도 냉각팬을 몇 분 더 돌려야 하는 예제에 적합한 타이머는?

💡 해설: 모터 정지 후에도 냉각팬이 일정 시간 더 동작해야 하므로 TOF(Off-Delay)가 적합합니다.

Q4. 설비 기동은 천천히 예열, 정지는 천천히 냉각시키고 싶을 때 각각 어떤 타이머를 쓰는가?

💡 해설: 기동시 지연은 TON, 정지시 지연은 TOF를 사용하는 것이 일반적인 조합입니다.

03. 점멸(깜빡이) 회로

1. 기본 원리

TON 타이머를 스스로의 출력을 되먹임(반전)시키는 형태로 구성하면 일정 주기로 켜졌다 꺼지는 오실레이터를 만들 수 있다.

2. ON/OFF 시간을 다르게 하려면

켜져 있는 시간과 꺼져 있는 시간을 다르게 하고 싶다면, TON 2개를 각각 다른 설정시간(PT)으로 두고 서로를 순서대로 기동시키는 방식으로 구성한다.

3. 응용 - 경고등 점멸

설비에 이상이 생겼을 때 일반 램프처럼 계속 켜두기보다, 점멸시켜서 시각적으로 더 눈에 띄게 하는 것이 안전 관리에 효과적이다. 경보 조건이 참일 때만 점멸회로가 동작하도록 AND 조건을 앞에 추가하면 된다.

4. 클럭 메모리(Clock memory) 활용

CPU 속성에서 클럭 메모리(Clock memory) 기능을 활성화하면, 별도의 타이머 로직을 짜지 않아도 미리 정해진 주기(0.5초, 1초 등)로 자동 반전되는 비트를 바로 사용할 수 있어 점멸회로를 훨씬 간단하게 구현할 수 있다.
✏️ 단원 확인문제 (4문제)
점수: 0 / 100점 (정답 0 / 4문제)

Q1. 점멸회로에서 ON시간과 OFF시간을 서로 다르게 만들고 싶다면?

💡 해설: ON시간과 OFF시간을 다르게 하려면 서로 다른 설정시간(PT)을 가진 TON 2개를 조합해 구성합니다.

Q2. 점멸회로의 핵심 원리는?

💡 해설: 점멸회로는 타이머의 출력을 스스로에게 되먹여 반전시키는 구조가 핵심입니다.

Q3. 설비 이상 경고를 일반 램프 점등 대신 점멸시키는 이유는?

💡 해설: 점멸은 계속 켜진 상태보다 시각적으로 더 눈에 띄어 안전 관리에 효과적입니다.

Q4. 별도의 타이머 로직 없이 미리 정해진 주기로 자동 반전되는 비트를 제공하는 CPU 기능은?

💡 해설: 클럭 메모리 기능을 활성화하면 정해진 주기로 자동 반전되는 비트를 바로 사용할 수 있어 점멸회로 구현이 간단해집니다.

04. 생산 개수 카운터

1. 예제 구성

컨베이어를 지나가는 제품을 감지하는 광센서 신호(I0.2)를 CTU(업카운터)의 CU 입력에 연결한다. 목표 수량을 설정값(PV)에 입력하면 그 개수만큼 지나갈 때 카운터 출력이 ON된다.

2. 리셋 처리

별도의 리셋버튼(I0.3)을 카운터의 R 입력에 연결해, 다음 배치를 위해 카운트를 0으로 되돌릴 수 있게 한다.

3. 누적 생산량과 배치 생산량 구분하기

하루 전체 누적 생산량을 계속 세고 싶다면 리셋을 자정에 한 번만 실행하는 별도 카운터를, 박스 단위 배치 생산량을 관리하고 싶다면 박스가 다 찰 때마다 리셋되는 카운터를 따로 두 개 운영하는 방식이 실무에서 흔히 쓰인다.

4. 카운터 값을 HMI에 표시하기

카운터의 현재값(CV)을 HMI 화면의 숫자 표시 필드에 연결해두면, 작업자가 실시간으로 생산 진행 상황을 확인할 수 있어 현장 관리에 큰 도움이 된다.
✏️ 단원 확인문제 (4문제)
점수: 0 / 100점 (정답 0 / 4문제)

Q1. 카운터의 현재값을 초기화(0으로)하는 입력은?

💡 해설: R(리셋) 입력이 켜지면 카운터의 현재값이 0으로 초기화됩니다.

Q2. 카운터가 도달하려는 목표값을 지정하는 파라미터는?

💡 해설: PV(Preset Value, 설정값)는 카운터가 도달하고자 하는 목표 값입니다.

Q3. 누적 생산량과 배치 생산량을 각각 관리하고 싶을 때 좋은 방법은?

💡 해설: 리셋 시점이 다른 두 목적(누적/배치)은 카운터를 따로 두어 관리하는 것이 실무에서 흔한 방식입니다.

Q4. 작업자가 실시간 생산 진행 상황을 확인하려면 카운터 값을 어디에 연결하면 좋은가?

💡 해설: 카운터의 현재값을 HMI 화면에 표시하면 작업자가 실시간으로 생산 진행 상황을 확인할 수 있습니다.

05. 컨베이어 순차 기동/정지

1. 기동 순서

컨베이어 3대를 한 번에 켜면 앞 컨베이어에 자재가 쌓일 수 있으므로, 맨 뒤 컨베이어부터 먼저 켜고 1초 간격으로 앞 컨베이어를 순서대로 기동시킨다. TON을 체인처럼 연결해 구현한다.

2. 정지 순서

정지할 때는 반대로 맨 앞 컨베이어부터 먼저 멈춰야 자재가 컨베이어 사이에 걸리지 않는다.

3. 인터록 조건 추가하기

앞 컨베이어가 정상적으로 돌고 있지 않으면(과부하 등으로 정지) 뒤 컨베이어도 함께 정지시키는 인터록 조건을 추가하면, 자재가 멈춰선 컨베이어 위에 계속 쌓이는 사고를 예방할 수 있다.

4. 비상정지와의 결합

비상정지가 눌리면 순차 정지 로직을 거치지 않고 모든 컨베이어를 즉시 동시 정지시켜야 한다. 순차 제어 로직과 비상정지 로직은 서로 다른 우선순위로 설계해, 비상정지가 항상 최우선으로 작동하도록 구성해야 한다.
✏️ 단원 확인문제 (4문제)
점수: 0 / 100점 (정답 0 / 4문제)

Q1. 여러 컨베이어를 순차기동할 때 일반적인 순서는?

💡 해설: 자재가 쌓이지 않도록 맨 뒤 컨베이어부터 먼저 기동시키는 것이 일반적입니다.

Q2. 컨베이어를 정지시킬 때는 어떤 순서가 안전한가?

💡 해설: 정지할 때는 맨 앞 컨베이어부터 먼저 멈춰야 자재가 걸리는 것을 방지할 수 있습니다.

Q3. 앞 컨베이어가 과부하로 정지했을 때 뒤 컨베이어도 함께 정지시키는 이유는?

💡 해설: 앞 컨베이어가 멈췄는데 뒤 컨베이어가 계속 돌면 자재가 쌓이는 사고로 이어질 수 있어 인터록을 추가합니다.

Q4. 비상정지가 눌렸을 때 컨베이어들은 어떻게 정지해야 하는가?

💡 해설: 비상정지는 순차 제어 로직보다 우선하여 모든 컨베이어를 즉시 동시에 정지시켜야 합니다.

06. 반복 동작(사이클) 타이머 응용

1. 예제 상황

교반기가 5초 동작, 3초 정지를 계속 반복해야 하는 경우처럼, 일정 패턴으로 동작-정지를 반복하는 사이클 제어가 필요할 때가 있다.

2. 구현 방법

동작시간용 TON과 정지시간용 TON, 총 최소 2개의 타이머를 서로 이어지도록 구성하면 이러한 사이클 동작을 만들 수 있으며, 각 타이머의 설정시간(PT)만 다르게 지정하면 동작/정지 시간을 원하는 대로 조절할 수 있다.

3. 사이클 횟수 제한하기

무한 반복이 아니라 정해진 횟수만큼만 반복하고 싶다면, 사이클이 한 번 완료될 때마다 카운터(CTU)를 1씩 증가시키고, 설정 횟수에 도달하면 전체 사이클 로직을 정지시키는 조건을 추가하면 된다.

4. 사이클 동작의 실무 활용 예

교반기 외에도 세척기의 분사-정지 반복, 도장 설비의 스프레이-이동 반복 등 일정 패턴을 계속 반복해야 하는 다양한 설비에 이 사이클 타이머 패턴을 응용할 수 있다.
✏️ 단원 확인문제 (4문제)
점수: 0 / 100점 (정답 0 / 4문제)

Q1. 일정시간 동작-정지를 계속 반복하는 사이클 동작을 구현할 때 필요한 최소 타이머 개수는?

💡 해설: 동작시간용, 정지시간용 각각 하나씩 최소 2개의 타이머로 사이클 동작을 구현할 수 있습니다.

Q2. 사이클 동작 중 '동작시간'과 '정지시간'을 서로 다르게 주고 싶다면?

💡 해설: 각 타이머의 설정시간(PT) 값을 다르게 지정하면 동작시간과 정지시간을 원하는 대로 조절할 수 있습니다.

Q3. 사이클을 무한 반복이 아니라 정해진 횟수만 반복시키려면?

💡 해설: 사이클이 완료될 때마다 카운터를 증가시키고 설정 횟수에 도달하면 정지시키는 조건을 추가하면 됩니다.

Q4. 사이클 타이머 패턴을 응용할 수 있는 설비로 가장 거리가 먼 것은?

💡 해설: 사이클 패턴이 필요 없는 단순 전원 콘센트는 이 응용 사례와 거리가 멉니다.

07. 카운터+타이머 결합 예제 (포장기)

1. 예제 상황

제품이 N개 모이면(CTU로 감지) 일정 시간(TON) 동안 포장 동작을 수행한 뒤, 카운터를 리셋하고 다음 배치를 기다리는 포장기 로직을 구성한다.

2. 로직 흐름

① 광센서 신호가 CTU의 CU에 들어가 개수를 카운트 → ② PV(목표 개수) 도달시 CTU 출력 ON → ③ 이 신호로 TON을 기동해 포장 모터를 설정시간만큼 동작 → ④ TON 완료 신호로 CTU를 리셋(R).

3. 컨베이어 정지와의 연동

포장 동작이 진행되는 동안에는 다음 제품이 포장 위치로 넘어오지 않도록 컨베이어를 잠시 정지시키는 조건을 함께 추가하는 것이 일반적이다. 포장 완료 신호가 나온 뒤에야 컨베이어가 다시 동작하도록 인터록을 건다.

4. 이상 상황 대비 - 타임아웃 처리

센서 고장 등으로 제품이 오랫동안 목표 개수에 도달하지 못하는 경우를 대비해, 별도의 타이머로 일정 시간 이상 카운트가 멈춰 있으면 경보를 울리는 타임아웃 로직을 추가하면 설비의 신뢰성을 높일 수 있다.
✏️ 단원 확인문제 (4문제)
점수: 0 / 100점 (정답 0 / 4문제)

Q1. 제품 N개가 모이면 포장동작을 시작하는 로직에서 개수 감지에 사용하는 명령은?

💡 해설: CTU(업카운터)로 제품 개수를 감지해 목표 개수(PV)에 도달했는지 확인합니다.

Q2. 포장동작이 끝난 뒤 다음 배치를 위해 카운터를 초기화하는 입력은?

💡 해설: 포장 동작이 끝나면 카운터의 R(리셋) 입력을 활성화해 현재값을 0으로 되돌립니다.

Q3. 포장 동작 중 컨베이어를 잠시 정지시키는 이유는?

💡 해설: 포장 동작 중에는 다음 제품이 겹치지 않도록 컨베이어를 잠시 정지시키는 인터록을 거는 것이 일반적입니다.

Q4. 센서 고장 등으로 오랫동안 목표 개수에 도달하지 못할 때를 대비하는 방법은?

💡 해설: 타임아웃 로직을 추가하면 이상 상황을 빠르게 감지해 설비 신뢰성을 높일 수 있습니다.

08. 종합 실습 - 신호등 제어

1. 예제 상황

신호등이 빨강(5초) → 초록(5초) → 노랑(2초) → 다시 빨강 순서로 계속 순환하는 로직을 구성한다.

2. 구현 방법

각 색상이 켜지는 시간을 지연시키기 위해 TON을 체인처럼 순서대로 연결하는 방식(또는 상태 전이 방식)으로 구현할 수 있으며, 마지막 단계의 완료 신호가 다시 첫 단계를 기동시키도록 연결해 무한 반복시킨다.

3. 보행자 신호 연동하기

차량 신호가 초록일 때는 보행자 신호를 빨강으로, 차량 신호가 빨강일 때는 보행자 신호를 초록으로 반대로 연동시키면 실제 교차로 신호등과 비슷한 구조를 만들 수 있다.

4. 점멸 모드 추가하기

심야 시간대나 점검 모드에서는 신호등을 순환시키지 않고 노란불만 점멸시키는 경우가 많다. 별도의 모드 선택 스위치를 두고, 이 모드일 때는 순환 로직 대신 3단원에서 배운 점멸회로가 노란 램프에 연결되도록 전환하는 구조로 확장할 수 있다.
✏️ 단원 확인문제 (4문제)
점수: 0 / 100점 (정답 0 / 4문제)

Q1. 신호등처럼 여러 단계가 순환하며 반복되는 동작을 구현하는 대표적 방법은?

💡 해설: 여러 단계가 순서대로 반복되는 동작은 TON 타이머를 체인처럼 연결해 구현하는 것이 대표적입니다.

Q2. 신호등 제어에서 각 색상이 켜지는 시간을 지연시키는 데 사용하는 명령은? (영문 3글자) (단답형)

💡 해설: TON(On-Delay Timer)을 사용해 각 색상이 켜지는 시간을 순서대로 지연시킬 수 있습니다.

Q3. 차량 신호가 초록일 때 보행자 신호는 어떻게 연동되어야 하는가?

💡 해설: 차량 신호와 보행자 신호는 서로 반대로 연동되어야 안전한 교차로 신호 체계가 됩니다.

Q4. 심야 시간대나 점검 모드에서 신호등이 흔히 전환되는 동작은?

💡 해설: 심야·점검 모드에서는 순환 신호 대신 노란불만 점멸시키는 경우가 흔합니다.
